# NEWSの追加・更新手順

NEWSは `content/newsPosts.ts` のファイルで管理します。外部CMS・有料サービスは使いません。

1. 最新のmainから作業ブランチを作成します。
2. `newsPosts` に記事を追加します。`slug` は半角英数字とハイフンで、既存記事と重複しない名前にしてください。
3. `title`、`category`、`summary`、実際の公開日 `publishedAt`（例：`2026-10-15`）、`body`、`status` を入力します。著者がある場合は `author` を追加します。
4. 初期状態は `status: "draft"` にします。下書きはトップ・一覧・詳細・サイトマップに公開されません。
5. 写真の掲載許可を確認し、元ファイルを加工せず `public/images/news/` にコピーします。`coverImage` にカード画像のパス、`coverImageAlt` に実際に写っている内容を記入します。写真なしの記事は淡い配色のカードになります。
6. 記事内写真は `additionalImages` に登録します。`afterParagraph` は本文の見出しを除いた段落番号（0から）です。`src` と `alt` を指定してください。写真は同じ3:4の枠に、縦横比を維持して全体表示します。元画像の再圧縮・切り抜きは行いません。
7. `body` の段落は空行（`\n\n`）で区切ります。先頭の `# 見出し` は記事タイトルとして一度だけ表示します。`**太字**` の署名と、単独段落の `https://...` 外部リンクに対応します。HTMLは本文に書かず、文章をそのまま入力してください。
8. 確認後に `status: "published"` にすると、トップ・一覧・サイトマップへ自動で追加されます。公開日の新しい順で表示し、同日なら登録順を維持します。
9. `node --test tests/news.test.mjs`、`npm run typecheck`、`npm run build` を実行します。Lintコマンドは既存プロジェクトにありません。
10. PC・スマートフォンでカード、全文、写真、リンク、ページ送りを確認し、既存手順でmainへ反映します。Vercelのデプロイ成功と本番表示を確認してください。

## 表示仕様

- トップ：通常のPCで4件、1680px以上で5件。1100px以下は3件、820px以下は2件、560px以下は1件ずつ移動します。
- 記事が画面内に収まる場合は矢印・インジケーターを表示しません。
- スワイプ、スクロールバー、Shift＋マウスホイール、左右矢印、キーボードの左右・Home・Endに対応します。通常の縦スクロールは妨げません。
- 一覧は1ページ12件。ページ送りで古い記事を閲覧できます。
- 記事URLは `/news/slug`。存在しない記事と下書きの記事は404になります。

## 初期記事

2026年10月15日を指定の公開日として登録しています。読み聞かせ写真を含む2枚について、依頼者から掲載許可確認済みの回答を受けています。初期2記事の原文と写真はテストでSHA-256照合します。本文を意図的に修正する場合は、原文確認後にテストの期待値も更新してください。

## 変更前へ戻す場合

変更前のmainは `codex/backup-before-news-20261014` に保存しています。他の作業を消すリセットはせず、このNEWS追加コミットだけをrevertし、ビルド・確認後に公開してください。
